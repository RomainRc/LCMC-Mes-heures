# LCMC · Mes heures

Application Android de suivi des heures pour **Le Coup de Main du Coin – Erdre et Loire**.

## Fonctions

- saisie séparée des horaires du matin et de l’après-midi ;
- reprise le soir d’une journée commencée le matin ;
- suivi mensuel des heures, du chiffre d’affaires et des jours travaillés ;
- gestion des exploitations clientes ;
- calendrier, export CSV et sauvegarde JSON ;
- données conservées localement sur l’appareil ;
- fonctionnement hors connexion.

## Télécharger l’APK

Ouvrir l’onglet **Actions**, sélectionner le dernier lancement réussi, puis télécharger l’archive **LCMC-Mes-Heures-APK** dans la rubrique *Artifacts*. Décompresser l’archive et installer `app-debug.apk` sur Android.

> Cette première version est signée automatiquement pour les essais personnels. Une clé privée dédiée sera nécessaire avant une diffusion sur le Play Store.
